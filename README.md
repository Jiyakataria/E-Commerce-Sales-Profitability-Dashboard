# 📊 Power BI Sales & Profit Dashboard

## 📌 Project Overview

This project is an interactive **Power BI Sales & Profit Dashboard** designed to analyze sales performance, quantity sold, profitability, customer behavior, payment methods, and product categories.

The dashboard provides an easy-to-understand overview of business performance through **KPI cards, charts, and interactive slicers**.

## 📂 Datasets Used

The dashboard uses two datasets:

### Orders Dataset

Contains order-level information such as:

* Order Date
* State
* Customer Name
* Payment Mode

### Details Dataset

Contains transaction-level information such as:

* Amount
* Quantity
* Profit
* Category
* Sub-Category

---

## 📈 Charts & Visualizations

### 1. KPI Cards

The dashboard includes four key performance indicators:

* **Sum of Amount** – Total sales amount
* **Sum of Quantity** – Total quantity sold
* **Sum of Profit** – Total profit generated
* **AOV (Average Order Value)** – Average order value

---

### 2. Sum of Amount by State

**Chart Type:** Horizontal Bar Chart

**Data Used:**

* Orders Dataset → `State`
* Details Dataset → `Amount`

This visualization compares the total sales amount across different states.

---

### 3. Quantity by Category

**Chart Type:** Donut Chart

**Data Used:**

* Details Dataset → `Category`
* Details Dataset → `Quantity`

This chart shows the distribution of quantity sold across different product categories.

---

### 4. Profit by Month

**Chart Type:** Column Chart

**Data Used:**

* Orders Dataset → `Order Date (Month)`
* Details Dataset → `Profit`

This visualization shows monthly profit trends and helps identify changes in profitability over time.

---

### 5. Sum of Amount by Customer Name

**Chart Type:** Column Chart

**Data Used:**

* Orders Dataset → `CustomerName`
* Details Dataset → `Amount`

This chart compares the total sales amount generated by different customers.

---

### 6. Quantity by Payment Mode

**Chart Type:** Donut Chart

**Data Used:**

* Orders Dataset → `PaymentMode`
* Details Dataset → `Quantity`

This visualization shows the distribution of quantities sold across different payment methods.

---

### 7. Sum of Profit by Sub-Category

**Chart Type:** Horizontal Bar Chart

**Data Used:**

* Details Dataset → `Sub-Category`
* Details Dataset → `Profit`

This chart helps identify the most and least profitable product sub-categories.

---

## 🎛️ Slicers

The dashboard contains interactive slicers for filtering the visualizations.

### Quarter

Available options:

* Qtr 1
* Qtr 2
* Qtr 3
* Qtr 4

**Data Used:**

* Orders Dataset → `Order Date (Quarter)`

### Category

The category slicer allows users to filter the dashboard based on product categories.

**Data Used:**

* Details Dataset → `Category`

These slicers allow users to dynamically explore the dashboard based on different quarters and product categories.

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using **Power BI Desktop**.
3. Use the **Quarter** slicer to filter the dashboard by quarter.
4. Use the **Category** slicer to analyze specific product categories.
5. Hover over charts to view detailed values.
6. Explore different visualizations to identify sales and profitability trends.
